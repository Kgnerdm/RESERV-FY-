# PLAN24 – Stakeholder Involvement Plan

This document identifies key stakeholders in the Reservify project, outlines their roles, and defines how they will be involved throughout the development process.

---

## 1. Stakeholder Identification

| Stakeholder         | Type           | Role in Project                                  |
|---------------------|----------------|--------------------------------------------------|
| End Users           | Affected       | Will use Reservify for appointment booking       |
| Small Businesses    | Affected       | Use the admin panel to manage schedules          |
| Course Instructor   | Reporting      | Reviews all project documentation and delivery   |
| Team Members        | Collaborators  | Responsible for all design, dev, and testing     |

---

## 2. Stakeholder Involvement Plan

| Stakeholder       | Involvement Type       | Activity                          | Deadline       |
|-------------------|------------------------|-----------------------------------|----------------|
| Instructor        | Reviewer               | Final documentation review        | 2025-04-30     |
| End Users (Demo)  | Simulated Feedback     | Usability walkthrough (test case) | 2025-04-29     |
| Businesses (Demo) | Use-case Review        | Simulate appointment creation     | 2025-04-29     |
| Team Members      | Ongoing Collaboration  | Weekly coordination & commits     | Continuous     |

---

## Summary

Key stakeholders in the Reservify project have been identified and their engagement has been defined to ensure alignment with both functional and academic expectations. All interactions are documented through GitHub and final reporting.
