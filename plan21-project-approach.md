# PLAN21 – Project Approach and Lifecycle

This document defines the project management approach and development lifecycle model selected for the Reservify project, along with justification for the choice.

---

## 1. Selected Lifecycle Model

| Lifecycle Model | Description                                               | When to Use                          |
|------------------|-----------------------------------------------------------|--------------------------------------|
| Hybrid (Scrum + Waterfall) | Combines agile sprints for frontend/backend with fixed planning for documentation and reporting | Ideal for academic projects with evolving features but fixed deadlines |

---

## 2. Project Approach

Reservify applies a **hybrid development strategy**:
- Planning and reporting phases follow **Waterfall**: fixed structure, formal documentation (PLAN/MC files)
- Development and integration follow **Scrum**: weekly task cycles, reviews, flexible prioritization via GitHub Issues and Project Board

## 3. Workflow Strategy

- Weekly sprints tracked via Issues & Project Board
- Retrospective updates documented in MC12, MC21
- Planning locked in early stage via PLAN series

---

## Summary

The hybrid model enables responsiveness in implementation while maintaining formal control over documentation and traceability—critical in an academic submission with real-life constraints.
