# MC33 – Work Environment Monitoring

This document captures any environmental or operational challenges encountered during the Reservify project and how they were addressed to ensure team performance and collaboration.

---

## 1. Work Environment Issues

| Environment Problem                  | Impact Level | Action Taken                          | Result                 |
|--------------------------------------|--------------|----------------------------------------|------------------------|
| Noise/distraction during Zoom calls | Medium       | Switched to shared Notion async logs  | Improved focus         |
| Confusion in task ownership          | High         | Updated assignments in PLAN12 + Board | Roles clarified        |
| Formatting inconsistency in reports | Low          | Created shared style template          | Standardized outputs   |
| Time zone scheduling conflict        | Low          | Agreed on shared window for check-ins  | Issue resolved         |

---

## 2. Communication & Collaboration Tools Used

| Tool             | Purpose                            |
|------------------|-------------------------------------|
| GitHub           | Task management, traceability       |
| Zoom             | Weekly meetings                     |
| WhatsApp         | Instant updates and coordination    |
| Google Docs      | Shared feedback and revisions       |

---

## 3. Notes

- All members worked remotely and asynchronously during part of the project
- GitHub Issues and project board were used to minimize communication delays
- Clear escalation path defined: notify PM for blockers, resolve within 24h

---

## Summary

The Reservify team successfully maintained a functional and responsive working environment by proactively addressing distractions, communication gaps, and collaborative friction points throughout the project cycle.
