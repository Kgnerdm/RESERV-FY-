## 3. Load Balancing Strategy

- Non-critical tasks are deferred to lighter weeks
- Team members redistribute work via GitHub issue re-assignments
- Project manager ensures no one exceeds their declared capacity
- Frontend and backend are developed in parallel to reduce wait time

## Summary

By tracking weekly availability and aligning it with the estimated task load, Reservify team ensures balanced contribution and timely delivery without burnout or overcommitment.
